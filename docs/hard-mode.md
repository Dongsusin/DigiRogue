# 하드모드

- 기존 기본 모드는 화면에서 **캐주얼**로 표시합니다. 저장 ID classic과 기존 클리어 기록은 유지합니다.
- 캐주얼 본편 200스테이지를 승리하면 하드·데일리·무한이 해금됩니다. 199스테이지, 패배, 선택 이벤트 전투, 다른 모드의 승리로 캐주얼 클리어를 대신하지 않습니다.
- 시작 디지몬 선택 화면의 좌우 모드 전환에 캐주얼 → 하드 → 데일리 → 무한 순으로 추가했습니다. 잠긴 모드의 시작과 저장 불러오기 모두 같은 해금 조건을 사용합니다.
- 하드는 200스테이지에서 끝나며 아군의 10스테이지별 레벨캡과 최종 Lv.200 상한을 유지합니다. 스캔·디지에그·스킬·마을 지원은 캐주얼과 같은 규칙을 사용합니다.
- 적만 하드 전용 레벨 구간과 체력·공방 보정을 적용합니다. 200스테이지의 적 레벨 구간은 Lv.204~240, 보스는 Lv.240입니다. 보스의 기존 진화·조그레스·분할 체력·특수 패턴은 유지합니다.
- 일반전, 중간보스, 보스 동료, 보스 진화·조그레스와 이벤트 전투가 같은 모드 정보를 전달합니다. 이벤트 미리보기와 실제 전투 모두 적의 아군 상한 초과를 허용합니다.
- 저장 복원은 현재 모드에서 적 보정을 다시 계산합니다. 중복 적용하지 않고 남은 HP 비율과 적 레벨을 보존하며 아군에 적 보정을 적용하지 않습니다. 자동 저장과 선택 저장 3칸에 하드 모드가 표시됩니다.
- 하드 최고 도달 단계와 클리어 여부를 기존 모드 기록에 별도로 저장합니다. 캐주얼·데일리·무한의 기록과 기존 저장 형식은 유지합니다.

## 구조와 밸런스 기준

src/progression/gameModes.js의 기존 모드 목록·해금 함수, modeProgress.js의 승리 기록, gameDifficulty.js의 공통 레벨·적 능력치 경로를 재사용합니다. 추가 난이도 계수는 HARD_MODE_BALANCE 한 곳에서 관리하며 기존 모드의 계산값을 바꾸지 않습니다. 사용자의 업그레이드를 상쇄하는 동적 난이도나 강제 패배 확률은 없습니다.

목표는 스킬·마을을 최대로 성장시킨 프로필에서 약 50%의 200스테이지 클리어입니다. 실제 플레이어의 승률을 확정하는 값이 아니라, 아래의 재현 가능한 자동 전투 기준으로 조정합니다.

- 스킬 267개 모두 최대 랭크, 시작 코스트 한도 25, 전체 마을 시설 Lv.3.
- 게임에서 동시에 선택할 수 있는 마을 지원은 하나이므로 교역소 Lv.3의 출발 골드 450만 적용합니다. 모든 시설의 보급을 한꺼번에 받지 않습니다.
- 실제 도감·시작 코스트 검사를 통과하는 8종류의 팀. 성장기 8마리, 궁극체 1마리와 성장기 동료, 성숙기·완전체 혼합, 소수 정예 초궁극체 등으로 구성합니다. 코스트 8~25, 파티 2~8마리.
- 실제 모듈의 전투 계산, 적 AI, 쿨다운·상태이상, 맵 보정·변칙, 보스 패턴, 동료 경험치, 능력치 진화, 단계별 회복, 랜덤 보상과 획득 골드로 구매하는 회복을 사용합니다. 라이벌 기억과 보스 최근 출현 이력도 이어집니다.
- 재추첨·무료 추가 보급은 없습니다. 전투 중 카드 사용, 자발적 전술 교체, 스캔·알을 통한 추가 영입, 선택 이벤트·의뢰 및 지역 신뢰 동료의 이점은 자동 정책에 포함하지 않습니다. 기술 8칸이 꽉 찬 뒤의 새 기술은 이 정책에서는 거절합니다.
- 조정에 쓰지 않은 난수 묶음으로 최종 클리어율을 다시 측정합니다. 실제 클리어율은 팀 선택과 전투·아이템 운영에 따라 달라집니다.

## 검사

- npm run test:hard: 해금, 기존 기록 호환, 독립 클리어 기록, 레벨캡, 전 모드 보정 분리, 전체 맵, 보스 진화, 저장 4칸, 이벤트 전투와 마을 지원.
- npm run simulate:hard -- <보고서.json> 96 --seed-start=2000: 기존 모험 시뮬레이터에 하드·최대 성장 옵션을 적용합니다. 일반 시뮬레이션은 기존 simulate:balance 명령을 사용합니다.
- 실제 화면 검사는 격리 프로필에서 모드 잠금, 시작, 저장·재개, 최종 승리 후 해금·종료와 여러 화면 크기를 확인합니다. 사용자 프로필 데이터는 변경하지 않습니다.
