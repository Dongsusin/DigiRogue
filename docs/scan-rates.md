## 기준

- 기본 능력치·시작 코스트에 쓰는 loreProfiles 전투력 예산을 재사용합니다. 현재 레벨·임시 강화·스킬로 할인된 시작 코스트는 수집 난이도를 바꾸지 않습니다.
- 블루 카드 기준 기본량은 30 × (405 / 전투력)²입니다. 단계별 상한은 유아기 60, 유년기 45, 성장기 40, 성숙기 25, 완전체 14, 궁극체 8, 초궁극체 4입니다.
- 아머체·하이브리드체는 기존 종별 육성 단계와 전투력을 함께 사용합니다. 매그너몬·카이젤그레이몬에 일반 성숙기 수집량이 적용되지 않습니다.
- 아이템 진화는 촉매 등급에 따라 일반 아이템 0.85, 희귀 0.65, 상위 희귀 0.45배입니다. 조그레스 대상은 0.7배입니다. 둘 다 해당하면 더 어려운 조건 하나를 적용합니다.
- 장비·스킬 보정 후 종별 배율을 한 번만 적용하고 반올림합니다. 양수인 표본은 최소 1%p, 총합은 최대 100%입니다. 조우·이벤트는 기존 기본 데이터 예산에 비례합니다.
- D-스캐너는 블루 카드 기본 데이터 예산 25를 35로 높입니다. 스킬의 기존 구매·등급·증가량은 유지하며 기본 데이터 보정에 합산합니다.

## 지급과 저장

조우, 블루 카드, 지역 이벤트, 이야기 보상 모두 addAnalysis를 거칩니다. 카드와 이벤트 미리보기도 같은 계산 결과를 사용합니다. 같은 종이 여러 마리 있어도 한 번의 표본만 지급됩니다. 이미 모은 수치는 다시 계산하지 않으며 기존 로컬 저장 포맷을 유지합니다. 부화 후 해금된 종에는 더 이상 스캔율을 쌓지 않으며, 데일리 모드의 스캔 제한도 유지합니다.

검증: npm run test:scan, 전체 scripts/verify-*.mjs 회귀 테스트, npm run build, npm run verify 및 verify -- --dist. 실제 브라우저 카드 사용·로그·로컬 저장·재실행도 별도로 확인합니다.
