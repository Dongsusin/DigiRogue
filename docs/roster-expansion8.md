## 변환 수정

- ReArise의 접두사 포함 원본 클립을 인식하고, 길이 0 또는 빈 트랙인 이름표는 제외한다. bd02만 있는 피격·넘어짐을 사망 모션으로 대체하지 않는다.
- 새 FBX 모델의 위치 좌표 단위를 보존해 렌더러의 가려진 면 판정에서 정상 몸체가 사라지지 않게 했다. 메쉬·애니메이션 압축은 유지한다.
- 스노우아구몬의 전용 흰색 텍스처를 적용하고 고글 재질을 제거했다. 보라색 에렉몬과 도우몬은 각각 원본 변종 텍스처·리그를 사용한다.
- 에렉몬(보라)의 과도하게 이동하는 special01을 제외하고 정상 원본 attack01/attack02를 유지한다. 스타소드의 평면 이펙트 카드는 제거하고 3D 검격으로 표현한다.
- 두 기승형은 Time Stranger의 원본 bd03를 사망 클립으로 사용한다.
