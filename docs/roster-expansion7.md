# 2026-10-13 로스터 확장과 계통 복원

확인한 신규 형태 153종 중 사용자 요청으로 3종을 제거하여 150종을 유지한다. 플레이 가능 종은 511종에서 661종으로 늘었고, 보스 전용 위그드라실을 포함한 모델은 662개다. 조사 후보 255개 중 실제 반영 및 미반영 상태는 [개별 체크리스트](asset-sources/roster-expansion7-coverage.json)에 남겼다. 모델 또는 원본 공격이 확보되지 않은 후보는 플레이 목록에 넣지 않았다.

## 모델 검증

Time Stranger 원본 106개와 The Models Resource의 FBX 44개를 반영했다. FBX 텍스처의 상하 방향, 복수 형태가 들어 있는 아카이브의 파일 식별, 폰체스몬 흑·백 매핑, Meshopt 이중 양자화로 인한 골격 파손, 다중 UV 얼굴과 눈, 과도한 루트 이동을 수정했다. 불안정한 선택 모션은 제외하되 원본 공격을 최소 하나 유지했다. 원본 전투 모션은 매니페스트와 [개별 출처 기록](asset-sources/roster-expansion7-evidence.json)에 남긴다.

New Century 36개 모델의 down은 원본 대기 자세를 유지하며 쓰러짐·소멸을 연출하는 보완 동작이다. 원작 전용 사망 모션으로 주장하지 않는다. 원본 공격과 피격 동작은 유지한다. 새 공격 키프레임을 만든 모델은 없다. 3종 제거 이전 GLB 153개의 23,953개 샘플 자세에서 비정상 바운드·과도한 이동 판정이 없었다. 이는 수치 검사이며 모든 기술을 실제 전투로 끝까지 수동 재생한 결과를 뜻하지 않는다.

## 진화 조건

- 유피테르몬은 아이기오투스몬[홀리]에서만 레벨·능력치 조건으로 진화한다.
- 블루·그린·다크·홀리 모드는 각각 전용 합성 코어를 사용한다.
- 유피테르몬[래스 모드]는 전용 아이템으로 진화하는 게임 내 초궁극체다. 공식 도감의 궁극체 분류와 구분한다.
- 크로노몬의 홀리·디스트로이 모드는 부텐몬에서 각각 전용 코어를 사용한다. 효코몬 → 부라이몬 → 부텐몬 계통을 유지한다.
- 메디벌듀크몬·패럴렐몬·좀비플루토몬·빅토리그레이몬 등 마스터 촉매 경로는 유지한다. 로그 에보류터 24종은 일반 진화로 전환했다. 상세 스피릿·아이템 변경은 [후속 기록](item-artwork-and-spirits.md)을 따른다.
- 진화 아이템은 항상 1개를 요구하고 1개만 소비한다. 기존 포지트론 레이저 ID와 레벨 조건은 유지한다.

## 임시 경로 복원

| 대상 | 이전 대체 재료 | 복원한 재료 |
| --- | --- | --- |
| 카오스몬 | 반쵸레오몬 + 카오스드라몬 | 반쵸레오몬 + 다크드라몬 |
| 제트메르바몬 | 미네르바몬 + 스패로우몬 | 메르바몬 + 스패로우몬 |

두 합체의 관계는 [카오스몬 공식 프로필](https://digimon.net/reference_en/detail.php?directory_name=chaosmon), [제트메르바몬 공식 프로필](https://digimon.net/reference_en/detail.php?directory_name=jetmervamon)에서 확인했다. 일반 선택 진화 54곳은 사용 가능한 로스터를 바탕으로 명시한 DigiRogue 경로이며, 공식 단일 진화표로 주장하지 않는다. 모든 경로는 기존 레벨·영구 육성·아이템 검사와 도감 생성기를 공유한다.

그레이드몬 → 도루고라몬, 도루그레몬 → 오류우몬의 교차 연결은 제거했다. 그레이드몬 → 알파몬, 도루그레몬 → 도루고라몬·알파몬, 히샤류우몬 → 오류우몬을 유지한다. 전용 아이템을 사용하는 메디벌듀크몬 경로도 유지한다. 옛 저장의 speciesData는 로드할 때 현재 경로로 갱신된다.

이번에 복원한 뿌띠몬(Deramon)은 프린스콩알몬과 다른 개체다. 이름 보정 이전 저장의 잘못된 뿌띠몬 표기는 프린스콩알몬으로 이관하되 현재 뿌띠몬의 도감·해금은 독립적으로 관리한다.

## 재현 및 테스트

원본 다운로드 → import-dsts-models / import-expansion-fbx → stabilize-dsts-motion → finalize-expansion-poses → 모델 검수 페이지에서 초상화 생성 → register-expansion7(최초 등록 전용) → restore-evolution-lineages 순서다. 캐시 의존성은 .cache/asset-tools에 분리했다. 새 아카이브가 이전 파일과 같다고 가정하지 않는다.

디지몬 661종 획득 및 아이템 200종 발견 테스트는 .tmp-convert/all-digimon-test.html에서만 사용하며 별도 로컬 저장 네임스페이스를 쓴다. 실제 로그인 계정 데이터와 구분한다. 위그드라실은 보스 전용으로 남긴다. 배포하지 않았다.

원본 게임 자산의 권리는 각 권리자에게 있다. Time Stranger 공개 뷰어 및 추출 기여자는 [Nuffle](https://nuffle.me/dsts-viewer)이며 [뷰어 코드 저장소](https://tangled.org/nuffle.me/dsts-viewer)를 참고했다. 뷰어 코드의 라이선스와 게임 모델의 권리는 별개다. 출처별 URL은 매니페스트에 보관한다.

## 사용자 요청에 따른 제거와 얼굴 수정

얼티메이트브라키몬·바커스몬[만취 모드]·오르디네몬은 로스터, 모델·초상화, 진화·조그레스·전용 아이템 및 도감 연결에서 제거했다. 일반 바커스몬과 브라키몬은 유지한다. 명시한 제외 목록으로 옛 해금 데이터나 개발 등록 도구가 다시 추가하지 않게 한다.

기자몬(chr594)은 얼굴 표현 UV의 퇴화 삼각형 때문에 눈 주변에 검은 면이 생겼다. 원래 diffuse UV로 얼굴·홍채·표정 텍스처를 합성하고 모델 및 두 초상화를 다시 생성했다. 다른 모델의 합성 정책과 원본 모션은 유지한다.
