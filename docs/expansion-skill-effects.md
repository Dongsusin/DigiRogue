# 추가 디지몬 고유 기술 이펙트

2026-10-13 기준, 최근 추가한 150종의 고유 기술 288개에 개별 연출을 연결했다. 기존 전투 계산, 기술 위력, 명중률, 상성 및 모델 애니메이션 파일은 변경하지 않았다. 효과의 형태와 색상은 공식 기술 설명을 게임 화면에 맞춰 재해석한 것이다.

## 적용 범위

\`src/data/expansionSkillEffects.json\`에서 종 이름과 기술 이름을 함께 사용한다. 같은 이름의 기술이라도 종별 발사 부위나 공격 방식이 다른 경우 분리된다. 기존 디지몬과 공통으로 사용하는 기술에는 종별 설정이 우선하고, 기존 공통 기술 설정은 계속 유지된다.

물대포·먹물·독성 분사·불꽃 브레스는 서로 다른 몸체를 사용한다. 음표·원반·부적·석판처럼 평평한 물체는 3D 메시를 카메라에서 읽기 쉬운 각도로 유지한다. 나선·분산·낙하 궤적은 이동 방향에 맞춰 회전하며, 광선은 움직이는 발사 부위를 계속 따른다.

## 색과 자원 사용

신규 물체의 유색 외피는 일반 투명 재질과 앞면 렌더링을 사용한다. 겹친 발광면으로 외곽 색이 하얗게 사라지는 현상을 줄이고, 작은 중심광·입자만 발광 효과로 남겼다. 광선에는 길이 방향 흐름과 나선 띠를 사용한다. 기존의 공유 발광 재질은 그대로 유지한다.

기하 데이터는 전투 효과 풀에 재사용한다. 개별 효과가 끝나면 재질과 동적 리본을 해제한다. 한 기술의 연사 수는 최대 8개이고, 여러 탄환의 마지막 타격에서만 기존 피해 표시를 갱신한다.

## 원본 메타데이터 수정

- 가비지몬: GLB에 없는 attack01 참조를 실제 attack02로 변경했다.
- 도그몬: 입·머리·몸의 발사 기준을 실제 Bip001 뼈에 연결했다.
- 브롯사몬: 원본의 비표준 뼈 이름을 고려해 꽃 높이에서 발사되도록 했다.

## 검증

\`npm run test:effects\`에 신규 150종의 원본 클립, 발사 뼈, 타이밍, 유한 좌표, 자원 해제, 기술별 대표 설정과 투사체 가독성 검사를 포함한다.

별도 로컬 검사 페이지는 실제 BattleRenderer와 원본 모델로 288개 기술의 준비·발사·진행·타격 화면을 렌더한다. 실제 게임에서도 0코스트 코로나몬으로 시작해 기술을 선택하고 적 HP가 감소하는 흐름을 확인한다. 전체 200스테이지 수동 플레이와 모든 기기의 성능 검증을 의미하지 않는다.

공식 설정 출처 150종은 [출처 목록](asset-sources/expansion-skill-effects-2026-10-13.json)에, 최종 검사 결과는 [검증 기록](validation/expansion-skill-effects-2026-10-13.json)에 남긴다. 배포하지 않는다.
