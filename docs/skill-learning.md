# 디지몬 기술 습득

기술은 해당 디지몬이 정해진 습득 레벨을 처음 통과할 때 한 번만 배울 수 있습니다. 현재 레벨 이전에 이미 습득 가능했던 기술은 다음 레벨업에서 다시 제안하지 않습니다.

- 기술이 8개 미만이면 새로 습득 레벨에 도달한 기술을 빈칸에 자동으로 배웁니다.
- 기술이 8개이면 기존 기술과 교체하거나 배우지 않을 수 있습니다. 거절한 기술이나 교체로 잊은 과거 기술을 이후 레벨업에서 반복 제안하지 않습니다.
- 경험치, 에보류터, 에보류터(골드), 여러 레벨을 한 번에 올리는 아이템에 동일한 판정을 적용합니다. 여러 습득 레벨을 통과하면 각 기술의 원래 습득 레벨로 한 번씩 안내합니다.
- 저장된 현재 레벨이 습득 기회의 기준입니다. 별도의 거절 목록을 추가하지 않아도 자동 저장과 선택 저장 3개 모두에서 이전 기술의 반복 제안을 막습니다. 아직 선택하지 않은 기술 교체창은 기존 수동 저장의 UI 체크포인트로 이어집니다.
- 레벨이 오르지 않는 능력치 갱신이나 저장 복원만으로 놓친 기술을 임의로 추가하지 않습니다. 시작·부화·진화 시 현재 형태의 초기 기술 구성은 기존 방식을 사용합니다.

구현은 src/App.jsx의 공통 습득 레벨 구간 판정을 사용합니다. 전투 경험치와 아이템 경로가 같은 기준을 공유하며 기존 8칸 기술 한도와 저장 형식은 유지합니다.

검사: npm run test:skills. 실제 게임 전투 함수를 사용하는 15개 회귀 검사로 거절, 교체, 다중 레벨업, 자동 습득, 중복 성장표, 레벨 상한, 자동·수동 저장, 독립 개체 및 512종의 과거 기술 반복 여부를 확인합니다.

2026-10-09 검증: 신규 습득 회귀 검사 15개와 전체 자동 검사 277개가 모두 통과했습니다. Vercel과 같은 publicDir=false 웹 빌드 및 별도 런타임 자산 검사(512개 모델·4,273개 모션·34개 맵)도 종료 코드 0으로 완료했습니다. 난이도·디지몬 능력치·기술 위력 수치는 변경하지 않았습니다.

실제 게임 UI 검사 16개도 통과했습니다. 가오몬의 Lv.25 아홉 번째 기술 제안에서 거절·교체를 각각 선택하고, 수동 저장·재개와 Lv.26 추가 레벨업 후에도 과거 기술을 다시 묻지 않고 기존 8칸이 유지되는 것을 확인했습니다.
