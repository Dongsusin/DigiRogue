## 제작과 출처

제작 방식은 AI가 작성한 선율·화성·리듬·편곡과 로컬 DSP 악기 합성입니다. 외부 음악 생성 서비스에서 받은 녹음물이 아닙니다. 기존 곡의 오디오·MIDI·멜로디·샘플·사운드폰트를 입력하거나 가져오지 않았습니다. 각 곡은 도입부, 주제, 변주/브리지, 재현, 반복부를 갖습니다.

44100 Hz 스테레오 Ogg Vorbis로 렌더링했습니다. 건반·벨·신스 리드·패드·베이스·기타형 합성음·킥·스네어·하이햇·탐·심벌을 배치하고, 스테레오 리버브·딜레이·약한 사이드체인·마스터 포화 처리를 적용했습니다. 리버브 꼬리는 시작부에 합쳐 반복 경계에서 잘리지 않도록 했습니다.

곡별 길이, 출력 SHA-256, 피크/RMS, 노트 수, 생성 seed는 public/BGM/ai/manifest.json에 기록합니다. 음질에 관한 수치 검증은 사람의 청취 평가를 대신하지 않습니다.

## 재생성과 설정

Python 3.12와 scripts/audio/requirements.txt의 패키지를 준비한 뒤 실행합니다.

`python scripts/audio/render_soundtrack.py`

개별 곡 ID를 인자로 전달해 해당 곡만 다시 생성할 수도 있습니다. 예를 들어 `python scripts/audio/render_soundtrack.py neon-horizon prism-canopy pulse-runners singularity-core starlight-harbor`는 추가된 5곡만 생성합니다. 부분 생성도 기존 곡의 메타데이터를 보존해 manifest를 병합·저장합니다. 이번 추가에서는 기존 5곡의 파일과 SHA-256을 보존했습니다. 재생성 뒤 `node scripts/generate-resource-versions.mjs` 또는 `npm run build`를 실행하면 파일 내용에 맞춰 캐시 해시가 갱신됩니다.

설정 → 오디오 → BGM 설정에서 각 곡을 켜거나 끄고 미리 들을 수 있습니다. 전체 OFF와 BGM 음량 0을 지원합니다. 기존 AI 5곡의 ON/OFF 선택은 유지하고 새 5곡은 한 번만 ON으로 추가합니다. 전체 OFF로 저장한 사용자는 새 곡도 OFF를 유지합니다. 이후 사용자의 선택은 저장됩니다. 꺼진 장면 음악은 다른 활성 AI 곡으로 대체되고, 전부 OFF이면 무음입니다. 미리듣기는 게임과 동일한 플레이어를 사용해 중복 재생을 방지합니다.
