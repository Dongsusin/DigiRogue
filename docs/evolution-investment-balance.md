# 진화 투자 난이도에 따른 플레이어 밸런스

2026-10-13, 밸런스 리비전 5. 플레이 가능한 511종을 점검하고, 아이템·추가 변신·복수 재료 합체 경로가 있는 91종을 강화했다. 수치와 촉매는 DigiRogue의 게임용 설계이며 공식 능력치나 공식 서열이 아니다.

일반 단일 진화는 기존 전투 성향과 종족값을 유지한다. 일반 촉매·모드 체인지 34종은 종족값 총합 +4%, 2체 합체 21종은 +8%, 상급 촉매·3체 이상 합체 27종은 +12%를 받는다. 아래 최상위 9종은 +20~28%를 별도로 적용한다. 능력치 분포는 기존 개별 성향을 따른다. 전용 기술은 실제 사용자별로 강화하며 공유 기술·계승 보조 기술은 일괄 강화하지 않는다.

모든 진화 아이템은 1개를 요구하고 1개만 소비한다. 진화 기억으로 면제된 경우는 소비하지 않는다. 진화 조건은 화면 표시와 실행 검사가 같은 함수를 사용한다. 최상위 형태는 성향에 맞춘 육성 능력치 3종을 요구한다. 고정 기준은 이전 형태의 종족값과 필요 레벨로 계산하며 최상위 요구치는 기준의 118% 또는 125%에 소량의 여유치를 더한다. 일반 특수 경로는 103~110%다. 임시 전투 버프·현재 HP·장비의 피해 증가로는 충족할 수 없고 추가 레벨 또는 영구 디지클론으로 충족한다. 육성 요구치 감소 스킬은 계속 적용된다.

조그레스는 모든 재료의 레벨과 육성 조건을 검사한다. 일반 조그레스 칩은 일반 등급을 유지한다. 알파몬[왕룡검]·얼티메이트카오스몬은 전용 마스터 에보류터 1개로 진화하며 일반 칩만으로 우회할 수 없다. 진화 기억은 아이템만 면제하며 재료 디지몬·레벨·육성 조건은 남는다. 전용 에보류터는 기존 정식 에보류터 이미지를 사용하는 게임용 촉매다.

그레이도, 오메가몬 X항체 인자, 오메가 블레이드, 블랙 디지트론 샘플 B, D 안티바이러스 B는 기존 아이템 ID를 유지한 채 마스터 등급으로 승급한다. 새 전용 에보류터 4종을 합쳐 마스터 진화 아이템은 9종이다. 기존 마스터 장착품 3종과 행운별 등급 확률은 유지한다. 보상·의뢰·아이템 도감은 같은 정의를 참조한다.

보스·라이벌·야생 적의 기존 종족값과 전용 기술 위력은 별도 전투 프로필로 보존한다. 시작 코스트는 기존 힘 기반 계산식에 강화된 총합을 반영하며 팀 한도 10~25 규칙은 유지한다. 이전 저장의 획득 상태·아이템 ID·HP 비율·선택한 기술 순서는 유지하고 플레이어 종족값을 한 번 갱신한다.
