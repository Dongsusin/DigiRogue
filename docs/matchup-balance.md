# 상성·일반 모험 전투 조정 (2026-10-11)

> 2026-10-12: 하드 전용 성장 계수와 동반 적 처리는 [하드 난이도 조정](hard-difficulty.md)에서 갱신했습니다. 아래 수치와 보스 유지 설명은 2026-10-11 변경 당시 기록입니다. 캐주얼·데일리·무한은 이번 조정에서 그대로 유지합니다.

상성이 무시되던 화염 표기 오류를 수정하고, 기술의 속성·물리/특수 구분·상태이상·방벽을 활용하는 일반 전투로 조정했습니다. 기준 소스는 커밋 cbf3f40532440ece81d5f403f70c9652f4fe4d66입니다.

## 상성과 기술 선택

- 화염/불, 전기/번개, 땅/흙 표기를 같은 속성으로 해석합니다. 데이터 파일의 기술 이름이나 연출은 바꾸지 않습니다.
- 타입은 유리 2배/불리 0.5배, 기술 속성은 유리 1.5배/불리 0.75배입니다. 각각 곱해 둘 다 유리하면 3배, 둘 다 불리하면 0.375배입니다.
- 타입 유리·속성 불리는 1.5배, 타입 불리·속성 유리는 0.75배입니다. 무속성 기술도 디지몬 타입 상성은 적용합니다.
- 실제 피해, 기술 미리보기, AI와 상성표가 같은 모듈을 사용합니다.
- 일반 적은 물리·특수 방어, 해당 종류의 방벽, 화상으로 인한 물리 위력 감소와 명중률을 보고 기술·대상을 함께 선택합니다. 도발 중에는 도발한 디지몬을 기준으로 기술을 고릅니다.
- 독·화상·행동 방해 기술의 평가는 적용 확률, 면역·보호막, 자연 치유와 남은 전투 길이를 반영합니다. 이미 상태이상이 있거나 곧 쓰러질 적에게는 추가 상태이상의 가치를 붙이지 않습니다. 실제 상태이상 수치와 지원 기술의 기존 효과·대기시간은 유지합니다.

## 일반 적 성장

아군 레벨 상한과 기존 영구 강화는 유지합니다. 추가 보정은 기존 공통 적 계수에 곱합니다.

| 모드 | 일반 적 추가 HP 시작→끝 | 추가 공격·방어 시작→끝 |
| --- | --- | --- |
| 캐주얼·데일리·무한 | 1.02→1.48 | 1.01→1.36 |
| 하드 | 1.10→1.40 | 1.0325→1.18 |

캐주얼의 200단계 일반 적은 기존 대비 HP 약 9.6%, 공격·방어 약 11.5%가 증가합니다. 하드는 각각 약 11.1%, 7.3% 증가합니다. 스피드는 별도 배율로 올리지 않습니다.

31단계부터 일반 적 전용 레벨 범위의 하한을 기존 범위 폭의 30%만큼 올립니다. 보스·라이벌이 사용하는 레벨 함수와 상한은 바꾸지 않습니다. 30단계까지의 종족 출현 가중치는 기존과 같고, 31~100단계에 걸쳐 맵에 원래 속한 강한 개체의 가중치를 점진적으로 높입니다. 기존 맵 풀과 단계별 종족값 상한은 유지하며 플레이어 파티를 보고 카운터를 생성하지 않습니다.

## 보스 유지 범위

보스·라이벌·특수 의뢰의 추가 계수, 레벨 규칙, 체력 구간과 패턴 정의는 그대로입니다. 일반 개체로 생성되는 보스 동반 디지몬도 기존 일반 적 계수를 따로 유지합니다. 일반 적의 레벨 난수 하나로 기존 범위의 의뢰 기준 레벨을 함께 저장하므로, 의뢰의 미리보기·실제 능력치·이어하기에 일반 적 상향이 새지 않습니다. 34개 맵 × 캐주얼/하드 × 5개 단계의 340개 생성 사례에서 이름·레벨·능력치·기술 목록·진화/체력 패턴이 변경 전과 일치했습니다.

공통 상성 규칙과 기술 평가 수정은 양쪽 전투원과 보스에게도 적용됩니다. 따라서 보스와 주고받는 피해량이나 선택 기술까지 과거와 같다는 뜻은 아닙니다. 보스에게 새 능력치 강화나 패턴을 추가한 변경은 없습니다.

## 검증

- 새로운 상성 회귀 검사 17개, 전체 Node 회귀 검사 406개 통과(종료 코드 0).
- ESLint 실행은 로컬 실행 파일 부재로 시작하지 못했습니다(MODULE_NOT_FOUND, 종료 코드 1). 린트 통과로 간주하지 않습니다.
- 게임 빌드와 배포 리소스 검사 성공(종료 코드 0): 모델 512개·모션 4,273개·맵 34개. 기존 500KB 이상 청크 및 플러그인 처리 시간 경고는 남아 있습니다.
- 격리된 브라우저에서 상성표, 실제 공격과 화상 피해, 화면 HP 및 새로고침 후 이어하기를 확인했습니다. 아구몬 HP 24→22, 쿠라몬 HP 20→8(직접 피해 11+화상 1), 이어하기 HP 22/8이 일치하며 콘솔 오류는 0개였습니다.

| 자동 정책 | 변경 전 클리어/패배/미종료 | 변경 후 클리어/패배/미종료 |
| --- | --- | --- |
| 무강화, 합법적인 기본 팀 48회 | 6 / 40 / 2 | 0 / 46 / 2 |

별도 seedStart 1000의 무강화 96회(전투당 최대 1,000턴)도 클리어 0 / 패배 91 / 미종료 5였습니다. 한 마리 시험은 아구몬·파피몬·팔몬·워그레이몬·메탈가루몬·오메가몬을 돌아가며 시작하며, 여러 마리 시험과 시작 종족 및 총 코스트가 동일한 짝 비교는 아닙니다.

위 표의 각 전투는 최대 300턴입니다. 미종료는 패배로 합산하지 않습니다. 동일 seed index를 사용하되 전투 판단의 변경으로 이후 난수 소비와 경로가 달라질 수 있습니다. 자동 정책에는 전투 아이템, 자발적 전투 중 교체, 스캔·알 영입, 선택 의뢰와 지역 지원이 없습니다. 무강화 정책은 이번 48회에서 클리어하지 못했으므로, 이 결과를 실사용자 클리어율이나 무강화 200단계 불가능의 증거로 해석할 수 없습니다. 실제 파티 영입과 교체를 포함한 장기 플레이 난이도는 추가 관찰 대상입니다.

독립 검토에서 발견한 의뢰 기준 레벨 누출과 상태 기술의 도발 대상 오지정을 수정했습니다. 검토자가 네 모드의 의뢰 48개 사례와 저장 복원 96개 사례, 상태 기술 실제 적용을 재확인했습니다. 별도로 진행 중인 음원 교체는 이 변경에 포함하지 않으며, 원래 음원 15개를 사용한 분리 소스에서 전체 검사·빌드·리소스 검증을 완료했습니다. 여러 마리 최대 강화 24회 수치는 동일 전투 모듈의 완료된 시험을 사용했으며, 분리 소스에서 시작한 해당 시험의 반복 실행은 프로세스 종료로 완료 기록이 없어 통과로 계산하지 않았습니다.

검증 수치와 소스 해시는 [검증 요약](validation/matchup-balance-2026-10-11.json)에 있습니다. 상세 로그·화면·변경 전 모듈은 저장소 밖 ../artifacts/digirouge-matchup-balance-2026-10-11에 보관합니다. 기존 2026-10-10의 600회 결과는 이전 규칙의 기록입니다.
