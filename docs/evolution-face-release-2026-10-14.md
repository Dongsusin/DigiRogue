# 2026-10-14 신규 진화 계통·얼굴·공격 동기화

## 진화와 디지에그

이번 추가 9종은 실제 게임의 진화 규칙과 같은 경로로 도감에 연결된다. 기존 디지에그의 유아기 부화 대상을 유지하고, 부화 이후 코로몬·뿔몬·와냐몬·레나몬·피요몬 계통으로 신규 일반 진화 분기를 연결했다. 성장기 이상을 알의 직접 부화 대상으로 넣지 않는다. 신규 형태마다 전용 진화 모티프를 사용하며 플래시 보정은 0이다.

- 코로몬 → 스노우아구몬 → 프리지몬/아이스몬
- 뿔몬/와냐몬 → 에렉몬(보라) → 폭탄모야몬/데블몬/모야몬
- 고부리몬 → 폭탄모야몬 → 가비지몬/디지타몬
- 레나몬 → 요우코몬 → 도우몬 → 쿠즈하몬
- 피요몬/츠카이몬 → 블랙버드라몬 → 가루다몬/야타가라몬
- 샤우트몬 + 스타몬즈 → 샤우트몬[스타소드] (디지크로스, 양쪽 Lv.15)
- 크레니엄몬 + 안바르몬 → 크레니엄몬[기승] (조그레스, 양쪽 Lv.75)
- 타이타몬 + 스컬벌키몬 → 타이타몬[기승] (조그레스, 양쪽 Lv.75)

기승 조그레스는 두 재료를 보유해야 하며 한 마리만으로는 실행되지 않는다. 기존 조그레스의 평균 레벨과 장착 아이템/기술 상속 규칙을 재사용한다.

## 얼굴 모델 수정

New Century 원본 계열 74종과 신규 9종을 실제 Three.js 렌더러로 확인했다. 17종을 수정했고, 전체 상세 모델과 동시에 그려지던 하위 LOD 메시 40개를 제거했다. 브롯사몬·캔들몬·째리몬은 원본 눈 PNG의 투명 영역을 컷아웃으로 복원했다. 원래 얼굴 이미지와 스킨/모션은 유지한다. 도감 및 선택 화면용 이미지 34개도 갱신했다.

수정 모델: 알로몬, 브롯사몬, 할매몬, 캔들몬, 가재드라몬, 째리몬, 페어리몬, 코스파이더몬, 블리자몬, 챠크몬, 레드베지몬, 바알몬, 이블몬, 슈츠몬, 아수라몬, 연체몬, 팅커몬.

변환기에도 같은 처리를 넣어 다시 가져오더라도 겹침과 검은 눈 카드가 재발하지 않게 했다.

## 스노우아구몬 리틀 블리자드

원래 방출 지점(모션의 48%, 소스 1.28초)은 J_joe 턱 관절이 거의 닫혀 있었다. 원본 프레임과 턱 관절을 측정해 입을 벌리는 75%(소스 2.00초)로 방출 지점을 옮겼다. 별도 애니메이션을 만들거나 기술 피해량을 변경하지 않았다. 실제 BattleRenderer에서 1·2·3배속별 방출 직전에는 냉기가 없고, 방출부터 명중까지 입이 열린 상태로 냉기가 유지됨을 확인했다.
