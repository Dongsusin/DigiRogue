# 디지몬 도감

메인 메뉴의 **도감**에서 디지에그별 부화·진화 계통을 볼 수 있습니다. 화면에는 디지몬 이미지와 사다리 형태의 연결선만 표시합니다.

- 현재 게임에 있는 디지에그 10종의 부화 목록에서 실제 진화 경로를 따라 구성합니다.
- 조그레스 재료 양쪽의 연결과 같은 세대의 모드 체인지도 포함합니다. 합쳐지는 디지몬은 한 계통도 안에서 한 번만 표시합니다.
- 현재 디지에그에서 도달할 수 없는 디지몬은 **기타 계통**에 실제 후속 진화와 함께 표시합니다. 임의의 부화·진화 관계를 추가하지 않습니다. 보스 전용·삭제된 디지몬은 제외합니다.
- 기존 발견 기록을 그대로 읽습니다. 발견·사용 가능 디지몬은 이미지, 미발견 디지몬은 **?**로 표시합니다. 미발견 이름이나 이미지 URL을 화면 요소에 넣지 않으며, 도감을 보아도 발견 기록은 변경되지 않습니다.
- 가로·세로 스크롤, 마우스 드래그, 확대·축소와 위치 초기화를 지원합니다. 이미지에 마우스를 올리거나 키보드로 선택하면 연결 경로를 강조합니다. 방향키로 이미지 사이를 이동하고 Esc로 메인 메뉴에 돌아갑니다.

이미지는 기존 3D 모델에서 만든 썸네일을 재사용하며 WebGL 모델을 추가로 띄우지 않습니다. 계통 계산은 게임에서 사용하는 병합된 진화 데이터와 동일한 경로 검사 함수를 사용합니다.

## 검증

```powershell
npm run test:dex
npm run build
```

`verify-digimon-dex.mjs`는 디지에그별 실제 경로, 전체 사용 가능 도감의 포함 여부, 조그레스·모드 체인지, 미발견 정보 숨김, 이미지 파일 존재, 순환·중복 데이터 처리 및 이미지와 연결선의 겹침을 검사합니다.
