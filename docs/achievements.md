# 업적과 출발 지원

메인 메뉴의 마을을 업적으로 교체했습니다. 업적은 프로필마다 최초 1회만 달성하고 스킬 포인트를 자동 지급합니다.

| 조건 | 보상 |
|---|---:|
| 각 등장 디지몬의 신뢰도 3 달성 | 2 SP |
| 각 라이벌 계열 제압 | 3 SP |
| 각 지역/중간 보스 제압 | 5 SP |
| 각 최종 보스 제압 | 10 SP |
| 캐주얼 / 하드 / 데일리 최초 200층 클리어 | 10 / 20 / 15 SP |
| 무한 모드 최초 200층 돌파 | 10 SP |
| 사용 가능한 디지몬 100% 획득 | 30 SP |
| 모든 도감 아이템을 한 번 이상 획득 | 20 SP |

업적 목록은 게임의 주민·라이벌·보스 데이터와 같은 정의를 재사용합니다. 아이템 도감의 분모는 보상과 공유하는 실제 아이템 카탈로그이며 공용 진화 아이템은 ID로 중복을 제거합니다. 발견만 한 디지몬과 보상에 표시되기만 한 아이템은 100% 획득 조건에 포함하지 않습니다. 즉시 사용되는 회복 아이템도 보상 확정 시 acquiredItemIds에 기록하여 다음 저장부터 복구할 수 있습니다.

달성 영수증·누적 획득 포인트·획득 아이템 원장은 기존 digirogue-trainer-skills-v1 안에 함께 저장됩니다. 스킬 리셋, 저장 슬롯 삭제, 새 모험, 신뢰도 감소로 달성이 취소되거나 보상이 재지급되지 않습니다. 계정/게스트의 기존 로컬 네임스페이스를 유지합니다. 저장이 거부되면 지급 완료로 표시하지 않습니다. 잠금을 기다리기 전에 계정별 digirogue-achievement-evidence-v1:UUID에 독립 영수증을 남기고, digirogue-achievement-pending-v1 재시도 원장도 유지하여, 스테이지가 진행되거나 신뢰도가 내려가도 이후 기록 처리·재시작에서 다시 지급합니다. 모든 저장 공간 쓰기가 거부될 때는 현재 창의 메모리에만 보관할 수 있습니다.

지원 브라우저에서는 프로필별 Web Locks로 업적·스킬 구매·리셋·진화 기억·스테이지 포인트의 전체 읽기/변경/쓰기를 직렬화합니다. 저장하고 나가기는 이 기록 저장의 완료까지 기다리며 실패하면 플레이와 대화상자를 유지합니다. 런처/테스트의 동기 저장에는 같은 프로필의 재진입 큐를 사용합니다.

기존 시설은 경험치 및 스캔율 → 출발 지원의 스킬 5종으로 옮겼습니다. 각 스킬의 단계별 비용은 2 / 3 / 5 SP입니다. 시작 골드, 식량, 회복 소모품, 탐색 장비, 부화 단축을 다루며 새 모험에만 적용하고 데일리에서는 적용하지 않습니다.

이미 확장한 시설의 단계는 같은 단계의 스킬로 한 번 이전합니다. 새 스킬 비용을 누적 획득 포인트에도 더하므로 이전 전후 사용 가능한 포인트는 같습니다. 원본 digirogue-town-v1은 이전 확인용으로 보존하며 게임에서 건설·주민 영입·지원 선택·마을 재료/증표 기능은 제거했습니다. 진행 중인 예전 저장의 townSupport는 해당 모험의 부화 단축만 호환합니다.

기존 신뢰도·수집·모드 기록과 남아 있는 저장에서 확인할 수 있는 라이벌 승리/획득 이력을 복구합니다. 이미 버려진 과거 저장에서 확인할 수 없는 보스 승리나 소비 아이템은 임의로 추정하지 않습니다.

검증: npm run test:achievements, 스킬·저장·계정·모드 관련 회귀 검사, 실제 브라우저 메뉴/지원 스킬/보상 획득, npm run build, npm run verify.
