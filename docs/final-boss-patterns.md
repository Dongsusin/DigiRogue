# 최종 보스 고유 패턴

200스테이지의 기존 최종 보스 8종에 적용한다. 체력 구간은 75% / 50% / 25%이며, 한 공격으로 한 구간만 깎이는 기존 규칙을 유지한다. 아래의 고유 패턴은 해당 구간에서 한 번만 발동한다. 진화를 제외한 패턴은 보스의 행동을 소모하므로 같은 행동에 일반 공격을 추가하지 않는다. 영상 컷씬은 사용하지 않는다.

| 보스 | 구간 | 고유 행동 |
|---|---|---|
| 아포카리몬 | 75% | 데스 에볼루션: 출전한 보유 디지몬을 실제 진화 이력의 직전 형태로 한 단계 퇴화시킨다. 이력이 없는 시작 디지몬은 현재 종의 연결된 이전 세대 중 가장 가까운 형태를 사용한다. 퇴화 불가능한 종·알·대기 멤버·지역 지원 동료는 제외한다. |
| 위그드라실 7D6 | 75% | 완전한 3D 모션을 가진 로열나이츠 중 한 마리를 소환한다. 적 최대 2마리, 아군 출전 멤버는 유지한다. 소환된 기사는 다음 턴부터 행동하며 일반 동료 적 난이도를 적용한다. |
| 아마게몬 | 50% | 살아 있는 쿠라몬을 흡수하고 최대 HP의 10%를 회복한다. 흡수한 쿠라몬을 다시 증식시키지 않는다. 살아 있는 쿠라몬이 없으면 흡수 회복도 없다. |
| 루체몬 | 75% / 50% | 기존 사탄 모드 진화 이후 게헤나를 전개해 물리·특수 피해를 50% 줄인다. 방벽은 기존 행동 타이머를 사용한다. |
| 알카디몬 | 75% / 50% | 기존 초궁극체 진화 이후 도트 매트릭스로 출전 중 한 마리의 HP를 소거한다. 해당 HP 패턴은 상태이상을 해제하고 행동불가·풀죽음·기술 대기시간과 별개로 발동한다. 세이프티 가드·생존 특성·자동 부활 프로그램은 적용된다. 일반 알카디몬 및 플레이어 기술에는 즉사 효과가 붙지 않는다. |
| 오메가몬 즈왈트 D | 50% | 백신 프로그램의 저항으로 공격·스피드가 약화되며 그 행동에는 공격하지 않는다. 25% 최후의 폭주에서는 공격을 다시 강화한다. |
| 바그라몬 | 50% | 출전 멤버의 기술·카드 스탯 증가를 지우고 해당 능력의 최대 25% 증가 효과를 자신에게 적용한다. 장착 아이템·영구 육성·감소 효과는 보존한다. |
| 데크스몬 | 50% | 프로세스 0으로 출전 멤버의 스탯 증가와 유리한 방벽 데이터를 분해한다. 감소 효과·도발·아이템·영구 육성은 보존한다. |

퇴화는 전투 후에도 유지된다. ID·레벨·경험치·장착 아이템·HP 비율·맵 효과를 보존한다. 퇴화 전에 예약한 전용 기술이 새 형태에 없으면 해당 명령을 취소하고, 남아 있는 상속 기술과 기본 공격은 사용할 수 있다. 즉사 후에는 기존 수동 교체 창을 사용한다. 최종 보스가 쓰러져도 소환된 적이 살아 있으면 전투는 계속된다.

저장에는 완료한 체력 구간, 소환 적, 실제 퇴화 형태가 함께 남는다. 이전 버전의 최종 보스 계획은 남은 구간의 정의만 갱신하며 이미 완료한 구간·행동 수·사용한 반응을 되돌리지 않는다.

## 검증

npm run test:bosses에 기존 보스 다양성 검사와 scripts/verify-boss-special-patterns.mjs를 함께 등록했다. 실제 App 전투 함수를 묶어 퇴화·즉사·부활·소환·저장·수동 교체·화면 갱신·예약 명령 취소를 검사한다. 새 패턴 적용 후의 전체 200층 클리어율은 다시 측정하지 않았으므로 이전 하드모드 시뮬레이션의 11.3% 결과를 새 버전의 수치로 해석하지 않는다.

- npm run build와 npm run verify -- --dist 종료 코드 0. 모델 512개·모션 4,273개·맵 34개 확인.
