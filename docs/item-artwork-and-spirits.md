# 2026-10-13 아이템 이미지와 스피릿 진화 정리

동일한 디지멘탈·스피릿은 한 아이템 ID로 사용한다. 이전 대상별 디지멘탈 ID와 스피릿 ID는 itemIdentity.json의 명시한 별칭으로 수량을 합산하고 발견 기록을 유지한다. X항체는 요청대로 기존 공용 이미지를 유지한다. 나머지 도감 아이템은 이미지 바이트 중복 검사를 통과해야 한다.

로그 등급의 공용 에보류터 그림을 사용하던 24종은 기존 부모·레벨과 영구 능력치 조건을 사용하는 일반 진화로 바꿨다. 이전 전용 아이템은 보상과 도감에서 제거한다. 마스터 진화의 레벨·능력치·재료 디지몬과 촉매 1개 조건은 유지한다.

## 원본 이미지 우선

디지멘탈 원화는 [공식 프로필 012](https://digimon.net/profile/report012/), 휴먼·비스트 스피릿 원화는 [공식 프로필 014](https://digimon.net/profile/report014/)를 사용한다. 기존 비스트 10종을 재사용하고 휴먼 6종의 원화를 추가했다. 지식·성실·순수 디지멘탈의 잘못된 에보류터 이미지를 실제 원화로 수정했다. 드라몬 브레이커와 메디벌듀크몬 X항체는 실제 게임 아이콘을 사용한다. 나머지 확인된 공용 아이템 원화는 기존 자산을 유지한다.

실제 단독 아이템 원화를 확인하지 못한 팬게임 전용 재료 17종만 imagegen으로 제작했다. 해당 디지몬의 갑주 색·무기·시간/태양/달/융합/칠대죄/봉인 모티프를 반영했다. 이는 공식 아이템 그림으로 주장하지 않는다. 최종 파일·SHA256·출처·생성 프롬프트는 [자산 기록](asset-sources/item-artwork-2026-10-13.json)에 남겼다. 출력은 투명 배경 256px WebP로 최적화했다.

## 스피릿

모든 스피릿은 일반(good) 등급의 장착 아이템이다. 보상으로 장착하며, 진화창은 가방 수량과 해당 디지몬의 장착 수량을 모두 확인한다. 진화 시 가방에서 먼저 소모하고 모자란 개수만 선택한 디지몬의 장비에서 소모한다. 진화 기억으로 면제된 경우에는 소모하지 않는다. 사용하지 않은 다른 장비는 유지한다.

| 휴먼 | 비스트 | 융합 |
| --- | --- | --- |
| 아그니몬 | 브리트라몬 | 아루다몬 |
| 볼프몬 | 가름몬 | 베오울프몬 |
| 페어리몬 | 슈츠몬 | 제트실피드몬 |
| 챠크몬 | 블리자몬 | 왕펭귄몬 |
| 라나몬 | 카르마라몬 | 현재 모델 없음 |
| 레베몬 | 현재 모델 없음 | 현재 모델 없음 |

휴먼과 비스트는 각각 해당 스피릿을 1개 요구한다. 융합 4종은 비스트에서 레벨 40 및 능력치 조건으로 진화하며 아이템을 요구하지 않는다. 휴먼에서 융합으로 건너뛰는 연결과 융합 스피릿 아이템은 제거했다. 새 모델이나 임의의 대체 디지몬은 추가하지 않았다.

## 황제드라몬

파일드라몬은 포지트론 레이저 1개로 드래곤·파이터 중 원하는 형태로 진화한다. 첫 진화의 레벨 60 및 육성 능력치 조건은 유지한다. 드래곤 ↔ 파이터는 이후 레벨·능력치·아이템 조건 없이 모드 전환할 수 있다. 레벨·경험치·장비를 유지하고 체력 비율은 기존 진화 방식으로 보존한다. 팔라딘은 기존 오메가 블레이드 조건을 유지한다. 옛 포지트론 코어 아이템 ID는 포지트론 레이저로 이관한다.

## 검증

node --test scripts/verify-item-artwork.mjs에서 일반 진화, 장착한 스피릿의 실제 소모, 가방·장비의 동시 보유, 미소모 장비 보존, 공용 디지멘탈로 여러 계통 진화, 옛 수량·발견 기록의 이관 및 중복 이미지 바이트를 검사한다. 별도 로컬 테스트 프로필은 현재 로스터와 도감 아이템을 모두 발견한 상태로 갱신한다. 배포하지 않는다.
