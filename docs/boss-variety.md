# 지역 보스 다양성 — 2026-10-09

모든 맵에서 스테이지에 따라 보스 후보가 한두 종으로 줄어들던 문제를 수정했다. 단순 프로필 개수가 아니라 실제 전투 시작 시 보이는 서로 다른 디지몬을 기준으로 최소 3종을 확보한다.

## 반영 내용

- 기존 3D 에셋을 재사용하는 지역 계보 29개를 추가했다. 일반 보스 프로필은 55개에서 113개, 중간 보스 프로필은 71개에서 100개가 되었다.
- 34개 맵마다 개별 서식지 목록을 지정했다. 같은 어둠 지역이라도 묘지, 네트워크, 황천에서 우선하는 계보가 다르다.
- 초반·후반, 10/20 계열 보스, 8/15 계열 중간 보스, 200단계 최종 보스 및 무한 모드의 200단계 반복 주기를 검사했다. 최종 보스는 기존 세계 위협 8종 풀을 유지한다.
- 최근 조우 기록에서 가장 오래 만나지 않은 종을 우선한다. 같은 종의 프로필이 여러 개여도 등장 확률이 중복으로 높아지지 않는다.
- 중간 보스의 예전 profileId가 매번 같은 계보를 강제하던 선택을 해제했다. 이전 만남·승리·적응 방벽 기록과 명시적 보스 ID는 유지된다.
- 기존 보스 55개가 모두 실제 후보로 도달 가능하며, 조그레스·아머·버스트·최종 보스의 편성도 유지된다.
- 모든 추가 계보는 idle/attack/damage/down이 있는 자연 모션 에셋을 사용한다. HP 50%/25% 제한과 진화 외 패턴의 행동 소비 규칙은 유지한다.
