# 차원의 통로와 데이터 개조

탐험 이벤트가 나오는 5·15·25…195스테이지의 승리 보상 처리 뒤에 일반 의뢰 대신 등장할 수 있다. 보스의 체력·패턴·단계, 보유 한도 8마리, 기존 계정 저장 방식은 그대로 사용한다.

## 차원의 통로

- 아직 통로를 제안받지 않은 판에서 탐험 지점마다 8% 확률로 등장한다. 200스테이지의 20개 지점을 모두 거치면 약 81% 확률로 한 번 등장하며, 한 판에 최대 한 번이다. 거절도 한 번의 제안으로 기록한다.
- 이용한다: 현재 맵을 제외한 전체 유효 맵에서 무작위 목적지를 결정한다. 다음 스테이지를 그 맵에서 시작한다. 스테이지·레벨 상한은 유지하고, 적·지역 효과·이후 보스는 도착한 맵을 따른다.
- 실제 맵 변경은 기존의 회복/부활 및 지역 강화 초기화 규칙을 사용한다. 다음 정규 맵 이동 시점부터는 기존 경로 진행을 따른다.
- 이용하지 않는다: 현재 맵을 유지하고 다음 스테이지로 진행한다.

## 데이터 개조 기계

- 통로가 선택되지 않은 탐험 지점에서 개조 가능한 보유 디지몬이 있으면 14% 확률로 등장한다. 사용하지 않고 지나갈 수 있다.
- 성공률 50%. 선택한 디지몬의 실제 진화 트리에 연결된 모든 후보에서 균등하게 하나를 고른다. 아이템 진화·모드 체인지·조그레스도 포함한다.
- 레벨·육성 능력치·아이템·합체 재료 조건을 검사하지 않는다. 아이템이나 다른 보유 디지몬을 소모하지 않는다. 성공 시 선택한 개체의 레벨·장착 아이템을 유지하고 기존 진화 연출을 사용한다.
- 실패하면 해당 슬롯의 개체를 계통에 연결된 부화 가능한 디지에그로 새로 만든다. 레벨 1, 장착 아이템·육성 강화·기술·상태·진화 이력 초기화. 가방 아이템과 다른 파티원은 유지한다. 부화는 기존 스테이지 대기 규칙을 따른다.
- 알도 보유 목록에 표시하되 개조할 수 없다. 실패하면 전투 가능한 동료가 한 마리도 남지 않는 대상은 선택할 수 없다. 부화 금지 규칙을 가진 데일리 모드에서는 개조 기계를 제안하지 않는다.
- 무상 개조 이력은 unpaidEvolutionSteps로 구분한다. 저장을 복원할 때 실제 아이템 사용을 기억하는 스킬의 사용 이력으로 잘못 추론하지 않으며, 이후 일반 진화·조그레스·퇴화에도 이 구분을 유지한다.

## 저장과 검증

- 목적지와 개조 난수는 이벤트 제안 시 저장한다. 선택 결과는 연출 전에 저장하고, 이미 처리한 선택과 이전 revision의 명령은 거부한다.
- 이벤트 진행/결과 및 예정된 통로 이동은 기존 자동·선택 저장에 함께 직렬화된다. 이어하기는 결과를 다시 지급하거나 난수를 다시 뽑지 않는다.
- 규칙은 src/adventure/anomalyEvents.js, 기존 탐험 분기는 explorationEvents.js, 화면은 AnomalyEncounter.jsx/CSS. App의 기존 진화/알 생성·맵 전환·저장 함수를 재사용한다.
- npm run test:anomalies: 발생 빈도, 전체 진화 후보, 무상 아이템/조그레스 진화, 장비 초기화·부화, 보유 슬롯, 데일리 제한, 실제 저장 파서 왕복, 중복 명령 방지 검증.
- 실제 브라우저에서 통로 이동, 일반/아이템/조그레스 개조 성공, 실패 후 동료 전투, 성공 결과 저장 복원, 800×450의 전체 선택 버튼 표시를 확인했다.
- 전체 200스테이지 수동 완주 및 모든 운영체제/브라우저 조합은 별도로 수행하지 않았다.
