# 마을 관리

메인 메뉴의 스킬 아래 마을에서 관리합니다. 진행 중인 전투에서는 건설이나 주민 영입을 하지 않습니다. 마을은 브라우저 로컬 저장소, 런처에서는 원자적으로 교체되는 로컬 세이브 파일에 영구 저장됩니다. 키는 digirogue-town-v1이며 기존 저장 데이터는 유지됩니다.

## 발전과 교류

처음에는 건설 데이터 80, 교류 증표 2, 에렉몬과 팔몬으로 시작합니다. 일반 스테이지를 실제로 승리하면 데이터 5, 10의 배수 스테이지는 데이터 15와 증표 1을 받습니다. 이벤트·의뢰 성공은 데이터 20과 증표 1입니다. 실패·도주에는 지급하지 않습니다. 모험 ID와 스테이지별 지급 기록으로 이전 자동/수동 세이브를 반복해 불러오는 중복 지급을 막습니다.

기존 지역 신뢰도 0~3을 그대로 표시합니다. 연결 지역 중 하나의 신뢰가 2 이상이면 증표 2로 주민을 영입할 수 있습니다. 이후 신뢰가 내려가도 영입한 주민은 떠나지 않습니다. 주민 영입은 전투 디지몬 해금과 별개입니다. 회관 확장에는 주민 수 조건(4명 / 8명)이 있으며 정원은 6 / 14 / 24명입니다.

## 시설

시설은 최대 3레벨이며 회관 레벨을 넘을 수 없습니다. 일반 시설 건설/확장은 데이터 30 / 70 / 140, 증표 0 / 1 / 2입니다. 회관 2/3 확장은 데이터 90 / 180과 증표 1 / 2입니다. 담당 주민이 있는 시설만 건설할 수 있습니다.

- 식량 농장: 팔몬. 감자튀김 / 햄버거 / 치킨 콤보 각 2개.
- 디지에그 보육원: 에렉몬. 새로 얻는 디지에그 부화 1 / 1 / 2스테이지 단축(최소 1). 2레벨부터 디지바이스 IC 제공.
- 회복소: 가트몬 / 엔젤몬 / 마린엔젤몬. 에너지필 A 1 / 2 / 3개, 3레벨에 디지소울 충전 1개 추가.
- 정비소: 톱니몬 / 가드로몬 / 안드로몬. D-터미널, 2레벨 D-스캐너 추가, 3레벨 디지바이스 IC 추가.
- 교역소: 모노크로몬. 출발 골드 150 / 300 / 450.

시설 지원은 동시에 하나만 선택하며 새 클래식·무한 모험의 시작 시점에 스냅샷으로 적용합니다. 이어하기의 진행 중 모험에는 소급하지 않고, 데일리에는 지원을 적용하지 않습니다. 선택을 바꾸거나 시설을 확장해도 기존 모험의 스냅샷은 유지됩니다. 지원 선택에는 추가 재료를 소모하지 않습니다.

## 검증

npm run test:town, 게임 기존 회귀 테스트, npm run build, npm run verify를 실행합니다. 실제 메뉴 → 건설 → 지원 선택 → 새 모험 → 저장/복원과 런처의 로컬 파일 저장도 확인합니다. 화면은 기존 마을 배경과 모델에서 렌더링한 썸네일을 재사용하여 별도 3D 마을이나 다중 WebGL 컨텍스트를 만들지 않습니다.

기존 세이브를 처음 연결할 때는 신뢰도 마이그레이션의 완료 의뢰 기록을 먼저 가져옵니다. 더 오래된 선택 전 세이브를 불러와 이미 완료한 의뢰를 다시 처리해도 마을 보상을 재지급하지 않습니다.

만나지 않은 주민은 주민 목록·시설 담당자·지역 신뢰 화면에서 이름과 초상화를 ?로 표시하며, 역할과 연결 지역도 숨깁니다. 모험의 이벤트에서 주민을 만나면 선택 결과나 신뢰 수치에 관계없이 공개됩니다. 신뢰가 0으로 내려가도 만남 기록은 유지되며, 처음부터 함께 사는 주민과 이미 영입한 주민은 항상 표시됩니다. 기존 세이브의 만남 기록은 시작 시 한 번 복구하고, 신뢰 수치나 보상을 되돌리지 않습니다.
