# 중간보스·라이벌 추가 패턴

최종보스를 제외한 보스 105개 구성과 라이벌 100개 구성에 등장하는 270종에 종별 패턴을 연결한다. 공통 동작은 14종이며, 각 종은 명시적인 목록에서 지정한다. 일반 야생전과 최종보스의 패턴은 이 목록을 사용하지 않는다.

## 행동과 우선순위

- 체력 구간 변화, 진화·조그레스, 기존 보스 규칙, 종별 추가 규칙 순으로 처리한다.
- 진화·조그레스는 기존처럼 일반 공격을 한 번 허용한다. 다른 패턴은 해당 디지몬의 행동을 사용한다. 같은 행동에 특수 행동과 일반 공격을 중복 실행하지 않는다.
- 동시에 조건을 만족한 규칙은 다음 자기 행동까지 보류한다. 이전 형태에서 보류된 종별 기술은 진화 후 제거하고, 사용한 규칙 기록은 저장·이어하기에 유지한다.
- 종별 특성 패턴과 대표 기술은 현재 형태에서 각각 한 번 사용한다. 기존 기술의 피해·속성·상태이상·대상 범위·3D 모션과 효과를 재사용한다. 별도의 영상 컷씬은 추가하지 않는다.

## 대표 행동

| 디지몬 | 추가 행동 |
|---|---|
| 크레니엄몬 | 아발론 방벽으로 물리·특수 공격을 방어 |
| 에테몬 | 러브 세레나데로 현재 전투 중인 아군의 공격 감소 |
| 데블몬 | 혼란을 유발하는 악마의 유혹 |
| 피노키몬 | 꼭두각시 실로 상대 속도 감소 |
| 피에몬 | 상대의 능력 상승 제거 |
| 샤크라몬 | 특수 공격과 능력 감소를 막는 결계 |
| 알포스브이드라몬 | 체력이 낮아지면 재생 |
| 묘티스몬 계열·우드몬 등 | 실제로 준 피해의 일부를 흡수 |
| 디아블로몬 | 빈 적 자리에 데이터 분신 한 마리 소환 |
| 아마게몬 | 빈 적 자리에 케라몬 한 마리 소환 |
| 워그레이몬 등 | 현재 종의 실제 대표 공격을 사용 |

흡수는 실제 피해의 25%, 해당 행동 전체에서 최대 체력의 8%를 상한으로 한다. 빗나감·무효·피해 0이면 회복하지 않는다. 소환은 적 최대 두 마리를 유지하며 한 번만 실행한다. 소환체는 보스 구간 체력이나 자체 보스 스크립트가 없는 일반 전투원이며 다음 턴부터 행동한다. 대기 멤버와 알은 적 대상 효과를 받지 않는다.

## 설정과 수치의 구분

설정에서 착안한 기술과 역할을 게임용 규칙으로 구현했다. 확률, 회복량, 발동 시점과 방어 지속시간은 팬게임의 밸런스 수치이며 공식 수치가 아니다. 디아블로몬 분신은 애니메이션에서 착안한 게임 내 표현이다. 모든 종이 각각 별도의 공식 특수 기술을 얻었다는 의미는 아니다.

공식 참고: [에테몬](https://digimon.net/reference_en/detail.php?directory_name=etemon), [크레니엄몬](https://digimon.net/reference_en/detail.php?directory_name=craniummon), [데블몬](https://digimon.net/reference_en/detail.php?directory_name=devimon), [묘티스몬](https://digimon.net/reference_en/detail.php?directory_name=vamdemon), [피노키몬](https://digimon.net/reference_en/detail.php?directory_name=pinochimon), [디아블로몬](https://digimon.net/reference_en/detail.php?directory_name=diablomon).

## 구현과 확인

- `src/data/encounterPatternRoster.json`: 종별 대표 기술과 역할.
- `src/data/encounterPatterns.js`: 발동 조건·종별 예외.
- `src/battle/bossEncounters.js`: 기존 체력 구간·진화 디스패처와 행동 우선순위.
- `src/battle/encounterPatterns.js`: 유한 흡수와 소환 처리.
- `scripts/verify-encounter-patterns.mjs`: 실제 전투 엔진을 통한 270종의 대표 기술·특성, 저장 복원, 진화·조그레스, 행동 소비, 대상 범위, 소환, 흡수 상한 검증.

실행: `npm run test:bosses`, `npm run test:regions`, `npm run build`, `node scripts/verify-runtime.mjs --dist`. 자동 전투 검증과 대표 화면 확인은 모든 3D 모션의 수동 시각 검수나 전체 200층 플레이를 대신하지 않는다.

대표 공격·흡수 공격이 개별 또는 공유 재사용 대기 중이면 규칙을 소모하지 않고 보류한다. 그 행동에는 사용 가능한 기존 행동을 선택하며, 준비가 끝난 뒤 보류된 대표 기술을 한 번 실행한다. 최종보스의 체력 구간 기술 예외는 변경하지 않는다.
