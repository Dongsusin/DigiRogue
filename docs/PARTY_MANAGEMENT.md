# 보유 디지몬 관리

알을 포함한 보유 한도는 8마리이며 시작 팀과 모험 중 영입에 같은 한도를 적용합니다. 지역 신뢰도로 보스전에 참여하는 일회성 동료는 보유 슬롯을 차지하지 않습니다.

8마리를 보유한 상태에서 디지에그 보상이나 스캔 부화를 선택하면 교체 창이 열립니다. 보유 디지몬 또는 알을 선택하고 교체를 확정하거나 영입을 취소할 수 있습니다. 교체를 확정하기 전에는 스캔 데이터·해금·골드·스테이지 진행을 변경하지 않습니다. 싸울 수 있는 마지막 디지몬을 알로 교체할 수는 없습니다.

기존 저장이 이미 8마리를 초과하면 초과한 디지몬을 정리 대기 목록에 보존합니다. 각각 기존 멤버와 교체하거나 보내주기를 직접 선택해야 합니다. 대기 중인 선택은 자동 저장과 선택 저장에 함께 보관되며 불러온 뒤 이어서 결정합니다.

진화·전투 교체·전투 불능 교체·아이템 대상·영입 교체·저장 슬롯에는 알도 표시합니다. 알에는 부화까지 남은 스테이지를 표시하며 진화나 전투 출전처럼 불가능한 행동은 선택을 막습니다. 긴 보유 목록은 내부에서 스크롤합니다.

검증 명령: `npm run test:party`. 스캔 회귀 검증은 `npm run test:scan`으로 실행합니다.
