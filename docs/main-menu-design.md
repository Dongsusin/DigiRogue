# 메인 화면 디자인

사용자가 제공한 메인 화면 이미지를 기준으로 기존 게임의 로고·계정 바·메뉴 구도를 적용했습니다.

- 로고와 계정 연결 영역은 중앙 상단에 배치합니다.
- 우측 하단 남색 패널 안에 새로하기와 이어하기를 넓게 배치합니다.
- 스킬/마을, 도감/설정은 두 열로 배치합니다. 기존 보유 스킬 포인트를 표시합니다.
- 메뉴별 SVG 아이콘, 금색 새로하기 버튼, 잘린 모서리와 파란 테두리를 사용합니다.
- 마우스 호버와 키보드 포커스는 기존 선택 상태를 갱신하고 밝은 테두리와 배경으로 표시합니다.
- 저장이 없으면 이어하기는 비활성화됩니다. 기존 저장 슬롯과 삭제 기능을 재사용합니다.
- 기존 1280×720 게임 캔버스가 화면에 맞게 함께 축소·확대됩니다. 세로 터치 화면의 회전 안내도 유지합니다.
- 기존 맵 배경 순환, 숫자 연출, 로그인, 로컬 저장, 게임 동작은 재사용합니다.

## 변경 파일

- src/components/MainMenu.jsx: 메인 메뉴 표시만 분리하고 기존 App 핸들러를 연결합니다.
- src/components/MainMenu.css: 로고·계정 바·메뉴 스타일을 관리합니다.
- src/App.jsx: 메뉴 컴포넌트와 메뉴 화면 전용 클래스를 연결합니다.
- src/App.css: 대체된 메인 메뉴 스타일을 제거합니다.
- src/components/TrainerSkillTree.css: 메인 메뉴용 스타일을 해당 컴포넌트로 옮깁니다.

새 의존성이나 대형 이미지 에셋을 추가하지 않았습니다.

## 검증 범위

브라우저 검사에서 실제 게임을 게스트로 열어 메뉴 진입과 복귀, 호버, 키보드 포커스, 0/3/10000 SP, 저장 유무, 저장 창의 모달 처리, 로그아웃, 기존 저장에서 실제 3D 전투가 로딩되는 흐름을 확인합니다. 실제 사용자 기록은 사용하지 않습니다.

확인 화면 크기: 1678×944, 1920×1080, 1440×900, 1280×720, 1024×768, 960×540, 844×390, 667×375, 2560×1440, 3440×1440, 390×844. 세로 터치 환경은 기존 회전 안내를 확인합니다.

실행 명령:

- node --test scripts/verify-auth.mjs scripts/verify-save-slots.mjs scripts/verify-digimon-dex.mjs
- npm run build
- node scripts/verify-runtime.mjs --dist
- git diff --check

UI 검증 스크립트와 캡처는 작업 폴더 외부 artifacts/digirouge-main-menu-2026-10-10에 보관합니다. 디자인 도구의 자동 변환은 별도 로그인/전용 브라우저 설치 문제로 사용하지 못했으며, 제공 이미지와 실제 브라우저 캡처를 직접 비교했습니다.

물리 기기 전체, Firefox/Safari, 실제 Google 계정 연결, 재패키징한 런처 설치 파일은 이번 검증에 포함하지 않습니다.
