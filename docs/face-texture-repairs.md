# 눈과 얼굴 텍스처 수정 — 2026-10-13

전체 662개 모델(플레이 가능 661종과 보스 전용 1종)의 초상화와 실제 3D 정면·측면을 조사했다. 13종의 눈/얼굴을 수정하고 26개 초상화를 다시 렌더링했다.

| 대상 | 수정 내용 |
|---|---|
| 사이케몬 | Next Order의 UV1 눈 레이어 복원. 2×2 표정 시트에서 기본 눈 한 프레임을 선택하고 원본 보라색 홍채 합성. |
| 기자몬, 파이라몬, 코쿠와몬, 수리몬, 패럴렐몬, 그레이스노바몬 | 접히거나 픽셀보다 좁은 UV2 면을 독립 아틀라스로 재배치. 경계 여백을 채워 검은 삼각형과 밉맵 번짐 방지. |
| 아이기오몬, 아이기오투스몬 및 블루·그린·다크·홀리 | 눈 위 음영 셸의 원본 반투명 색과 알파 적용. 불투명 흰색 셸이 홍채를 가리는 문제 수정. |
| 토우몬 | 눈과 별개인 42정점 몸통 효과 메시의 누락 UV를 기존 기본 샘플과 같은 상수 UV로 명시. |

몸체 텍스처의 알파가 마스크로 쓰이는 경우 RGB를 보존하며 눈 레이어만 알파 합성한다. 눈을 새로 그리지 않고 원본 게임 이미지를 사용했다. 게임 파일에서는 기존 애니메이션 9,834개 채널의 시간·값·보간을 그대로 보존했고 13종의 삼각형 수 357,596개도 동일하다.

## 검증

- `npm run test:faces`: 10개 회귀 검사 통과.
- 로스터 회귀 검사: 44개 통과.
- 662개 GLB, 1,870개 프리미티브의 재질/UV 검사 통과.
- 수정 13종의 128개 클립을 3개 시점씩 검사: 384개 포즈, 정면·측면 768뷰, 렌더 오류 0.
- 실제 사이케몬 선택 및 컬러풀 스파크 사용 확인: 적 HP 16 → 8, 페이지 오류 0.
- 리소스 버전 생성, Vite 빌드, 다운로드 패키징, 런타임 검증 모두 종료 코드 0.

검증 범위는 Chrome/SwiftShader와 위 샘플 시점이다. 전체 662종의 모든 애니메이션 프레임을 모든 GPU에서 직접 검증한 결과는 아니다. 배포하지 않았다.
