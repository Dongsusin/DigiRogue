# 디지에그 계통 연결 보완

기준일: 2026-10-11. 기존 10개 디지에그의 부화 목록과 기존 진화 경로는 유지한다. 기타 계통에서만 보이던 163종을 연결해 플레이 가능한 511종 모두 알 계통에 포함한다. 보스 전용 위그드라실은 대상이 아니다.

`src/data/evolutionTreeConnections.json`의 추가 경로를 `getEvolutionTargets`에 합친다. 도감과 실제 진화 선택 화면이 같은 경로를 사용한다. 레벨·육성 능력치·아이템 조건은 기존 엔진을 따르며, 조그레스는 모든 재료의 레벨과 조그레스 아이템/학습한 진화 기억을 확인한다.

## 근거와 게임용 보완의 구분

## 회귀 검사

`npm run test:dex`: 알 계통만으로 511종 포함, 모든 합체 재료를 갖춰야 하는 획득 가능성, 신규 경로의 실제 진화 선택 노출과 조건, 신규 조그레스의 재료 누락/레벨 부족/아이템 미사용 거부, 이전 저장의 경로 갱신, 미발견 정보 비공개, 정면 이미지 존재, 하향 트리의 선·초상화 교차 방지 및 접기 동작을 검사한다.

기본값은 모든 가지 펼침이다. 공유 진화와 순환 경로는 별도 참조 초상화로 표시해 긴 교차선을 만들지 않고 원래 가지로 이동할 수 있게 한다.
