# 추가 디지몬 진화 연출과 디지에그 연결

2026-10-14. 로컬 테스트용 적용이며 배포하지 않았습니다.

## 적용 범위

추가 150종의 연출 데이터를 종별로 지정했습니다. 그중 유아기 5종은 기존 부화 장면으로 등장하며, 나머지 145종은 실제 게임의 진화 경로에서 새 연출을 사용합니다. 진화 단계, 아이템, 조그레스 재료, 능력치 조건은 변경하지 않습니다.

공식 프로필은 기존에 조사한 [원문 출처 목록](asset-sources/expansion-skill-effects-2026-10-13.json)을 참고했습니다. 공식 영상 복제가 아닌, 게임에 있는 실제 3D 모델과 네이티브 idle·victory 모션을 활용한 자체 연출입니다. 공격 모션을 새로 제작하지 않습니다.

## 종별 방향

- 코로나몬·파이라몬·플레어몬·아폴로몬: 태양 원반과 불씨, 갈기 방향의 광선.
- 그레이스노바몬: 아폴로몬의 태양과 디아나몬의 달 색상을 가진 두 파트너가 융합합니다.
- 아이기오몬·가와파몬·세이렌몬·삼장몬: 피리·음악·경전의 이미지에 맞춘 음표와 공명.
- 아이기오투스몬: 용의 결정. 블루는 사이보그 조립, 그린은 식물, 다크는 어둠, 홀리는 빛의 결정으로 모드 전환을 구분합니다.
- 크로노몬 홀리: 시계가 정상 방향으로 돌아 시공을 복원합니다. 디스트로이는 역회전과 파편으로 시간의 붕괴를 표현합니다.
- 유피테르몬 래스 모드: 천체 배경과 번개 심판. 일반 진화와 모드 전환을 구분합니다.
- 클라비스엔젤몬: 열쇠. 베오울프몬·부라이몬은 두 자루 검, 빅토리그레이몬은 대검, 메디벌듀크몬은 창을 사용합니다.
- 아라크네몬·스파이더몬·코스파이더몬: 거미줄과 고치. 브롯사몬·플로라몬·케레스몬 미디엄은 꽃·꽃가루·수확을 표현합니다.
- 티아루도몬·라이지루도몬·브리웨루드라몬: 각각 얼음·전기·불의 방패 결계.
- 기계·비행·수생·화석·갑각·곤충 계열: 조립, 기어, 기류, 물결, 영혼, 결정, 칼날 등으로 구분합니다. 전체 명단은 아래 검증 기록에서 확인할 수 있습니다.

7종의 새 입체 모티프(태양·검·음표·시계·거미줄·꽃·방패)를 추가했습니다. 이번 150종에는 총 26가지 모티프, 123가지 모티프/변형 조합을 사용합니다. 공통 흰색 플래시와 빠른 와이어 깜박임을 없애고, 배경 광량·공통 입자·이동 궤적을 줄여 종별 효과가 보이도록 했습니다. 평면 형태를 가진 3D 상징은 카메라를 향해 두께와 형태가 읽히게 회전합니다.

## 디지에그

새 알 아이템을 중복 추가하는 대신 기존 알의 부화 가능 목록을 확장합니다. 기존 10개 알의 순서·보상 ID·이미지를 유지합니다.

| 추가 유아기 | 기존 연결 | 추가 연결 | 다음 단계 |
| --- | --- | --- | --- |
| 쟈리몬 | 용기 | 우정 | 기기몬 |
| 뽈뽈몬 | 지식 | 성실 | 카프리몬 |
| 피치몬 | 성실 | 사랑 | 둥실몬 |
| 유라몬 | 순수 | 친절 | 시드몬 |
| 제리몬 | 친절 | 희망 | 구미몬·초코몬 |

알에서 나오는 대상은 전부 실제 사용 가능한 유아기입니다. 기존 저장에 들어 있는 알도 현재 부화 목록을 사용합니다. 부화 후 실제 진화 선택 함수를 통해 낮은 레벨에서 초기 성장 경로가 열리는지 확인합니다. 과거에 제거한 옷코몬·모르포몬 알은 되살리지 않습니다.

## 파일과 검증

- 연출 지정: src/data/rosterExpansion7Cinematics.js
- 연출 선택: src/data/evolutionCinematics.js
- 3D 효과: src/three/evolutionMotifs.js, CinematicEvolutionRenderer.js
- 플래시 제어: src/three/cinematicTimeline.js
- 알 연결: data/디지몬/디지에그.json

- 자동 검사: npm run test:evolution-scenes
- 전체 결과: [검증 기록](validation/expansion-evolution-scenes-2026-10-14.json)

검증은 실제 진화 경로, 부화 소비 함수, 네이티브 모델 로드, 장면의 주요 단계, 일시정지·시간 이동, 모션 감소, 화면 크기와 건너뛰기를 대상으로 합니다. 모든 경로의 장시간 수동 플레이를 대신하지는 않습니다.
