# 하드 난이도 조정 (2026-10-12)

스킬·마을 최대 강화 기준 200단계 클리어율 약 10%를 목표로 하드 전용 적 성장 곡선을 조정했습니다. 최종 새 시드 256회 자동 검증은 **클리어 29회 / 패배 227회 / 미종료 0회, 클리어율 11.3%**입니다. 정해진 자동 정책의 관측값이며 실제 사람의 승률을 보장하는 수치는 아닙니다.

## 적용 범위

- 적 레벨 곡선은 기존 하드 그대로입니다. 200단계 기본 적 레벨 범위의 상한은 240이며 아군은 기존 10단계별 상한과 최종 Lv.200을 유지합니다.
- 일반 적·중간보스·보스·특수 의뢰의 체력과 공격/특공/방어/특방 보정을 단계에 따라 올립니다. 스피드에는 이 추가 배율을 적용하지 않습니다. 종족별 원래 능력치 비율과 기술·패턴은 유지합니다.
- 보스의 일반 동반 디지몬도 하드 일반 적 성장 곡선을 사용합니다. 기존의 낮은 별도 동반자 계수는 하드에서 제거했습니다.
- 플레이어 강화 상태나 승패에 따라 적을 바꾸거나 클리어를 확률로 차단하지 않습니다.
- 캐주얼·데일리·무한은 변경하지 않았습니다. 실제 전투 생성 34맵 × 3모드 × 9단계, 총 918사례가 변경 전과 같습니다.

## 검증 조건과 결과

기준 소스는 0f35cbe입니다. 같은 실제 전투 엔진과 최종 정책 v4를 사용한 변경 전 64회는 39클리어 / 25패배 / 0미종료였습니다. 최종 검증과 시드 범위가 다르므로 짝 비교나 사람 대상 통계로 해석하지 않습니다.

- 트레이너 스킬 262개 모두 최대 단계, 마을 6개 건물 모두 3단계, 전 종족 해금 상태입니다. 출발 지원은 실제 게임처럼 한 종류만 선택하여 상점 지원(+450G)을 사용했습니다.
- 8가지 합법적인 시작 팀을 균등하게 32회씩 시험했습니다. 코스트는 25 이하이며 성장기 기본 팀부터 고코스트 소수 팀까지 포함합니다.
- 실제 적 AI·상성·피해·상태이상·진화 조건·보스 구간 패턴·맵 연결·회복·보상·획득 골드 소비를 사용합니다. 임의 아이템이나 부활을 넣지 않습니다.
- 지원 기술은 실제 UI의 자동 아군 대상 선택을 재사용합니다. 회복·방어 반복으로 진행이 멈추면 공격이나 대기 멤버 교체를 시도합니다. 교체는 행동을 소모하고 실제 상태이상·패시브·대기시간 처리를 한 번 수행합니다.
- 최종 seed index는 7000~7255, 난수 시드는 index × 7919 + 17입니다. 조정에 사용한 0~127, 5000~5255, 6000~6255와 겹치지 않습니다.
