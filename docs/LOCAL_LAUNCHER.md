# 디지로그 다운로드 버전

`../play-hub`의 AURORA Launcher 1.2.3에서 게임을 설치하고 실행한다.
로그인 화면 없이 메인 메뉴가 열리며 첫 실행에 만든 로컬 게스트를 계속 사용한다.
기존 모험, 도감, 분석, 스킬, 게임 모드, 설정과 자동/선택 저장 슬롯을 유지한다.

런처의 IPC 저장 연결을 사용하며 진행 기록은 다음 파일에 보관한다.

```text
%APPDATA%/AURORA Launcher/saves/digilog/main.json
%APPDATA%/AURORA Launcher/saves/digilog/main.backup.json
```

게임 설치 폴더와 분리되어 있으므로 업데이트, 삭제, 재설치 후에도 기록을 유지한다.
이전 AURORA 버전의 로컬 진행 기록은 같은 프로필에서 첫 실행에 한 번 이관한다.
기록 저장이 거부되면 메모리 값을 바꾸거나 저장 성공으로 표시하지 않는다.
손상된 기존 파일을 빈 파일로 덮어쓰지 않으며 시작 오류와 재시도 버튼을 표시한다.

게임 데이터, 이미지, 소리와 3D 모델은 설치 패키지에 포함한다.
런처 실행은 Google 로그인이나 인터넷 연결을 요구하지 않는다. 웹 버전의 Firebase 로그인과 분리하여 기존 로컬 게스트 및 파일 저장을 사용한다. 웹 배포는 [별도 기록](WEB_AUTH_DEPLOYMENT.md)을 참고한다.
일반 `npm run dev`는 개발용 브라우저 저장을 사용하고, 런처에서는 파일 저장이 우선한다.
